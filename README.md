# 쉬운 AI (웹 버전)

AI에게 역할을 정해 주고 쉽게 대화하는 웹 앱입니다. `index.html` 파일 하나로 동작합니다.

## 쓰는 방법

- `index.html`을 브라우저(Chrome, Edge 권장)로 열거나, GitHub Pages 같은 곳에 올려서 엽니다.
- 처음 열면 **브라우저 안의 AI**가 기본으로 골라져 있습니다. 가운데 **AI 준비하기**를 누르면, 설치나 키 없이 바로 실습할 수 있습니다 (처음 한 번 AI 파일을 받는 데 몇 분 걸립니다).
- 다른 AI를 쓰려면 왼쪽 **AI 연결**에서 고릅니다.
  - **브라우저 안의 AI (기본)**: 설치도 키도 필요 없습니다. Chrome, Edge 같은 WebGPU 지원 브라우저가 필요합니다.
  - **내 컴퓨터의 Ollama**: 무료. PC에 [Ollama](https://ollama.com/download)가 설치되어 있어야 합니다.
  - **Claude**: Anthropic API 키가 필요합니다.
  - **OpenAI 호환 서비스**: OpenAI, OpenRouter, Groq, LM Studio 등. 주소와 키를 넣습니다.

## 실습 자료 (새솔고 학생회 도우미 만들기)

사이트 오른쪽 위 **실습 자료 받기**를 누르거나, 3단계와 4단계 아래의 **예시 파일** 링크를 누르면 바로 받을 수 있습니다. 모두 실습을 위해 지어낸 **가상의 학교** 자료입니다. 같은 파일이 [`실습자료`](실습자료) 폴더에도 있습니다.

| 파일 | 쓰는 곳 |
|---|---|
| 규칙_학생회도우미.txt | 3단계: 답변 규칙과 흐름 |
| 참고자료_상점벌점규정.txt | 4단계: 참고 자료 |
| 참고자료_주요일정.pdf | 4단계: 참고 자료 |

## 챗봇 만드는 순서 (화면 왼쪽 1 to 4)

1. **챗봇 이름**: 대화에서 AI 대신 이 이름으로 답합니다.
2. **역할**: 어떤 챗봇인지 적습니다. 예시 역할 버튼으로 시작해도 됩니다.
3. **답변 규칙과 흐름 (선택)**: 답할 때 지킬 규칙이나 대화 순서를 적거나, **규칙 파일 불러오기**로 TXT 파일을 불러옵니다. 칸에 파일을 끌어다 놓아도 됩니다. 그다음 **역할과 규칙 적용**을 누릅니다.
4. **참고 자료 (선택)**: PDF, TXT 파일을 넣습니다. 질문할 때마다 자료에서 관련 있는 부분을 찾아 AI에게 함께 보여 주고, 답변 아래 **참고한 자료**를 누르면 어느 문장을 참고했는지 볼 수 있습니다.

규칙 파일 예시:

```
1. 모든 답변의 첫 문장은 "도서관 안내입니다."로 시작하세요.
2. 답은 두 문장 이내로 짧게 하세요.
3. 자료에 없는 내용은 "자료에 없는 내용이에요."라고 말하세요.
```

브라우저 안의 AI는 작은 AI라서 규칙을 항상 지키지는 못합니다. 규칙은 짧고 분명하게, 3 to 5개 정도로 적을 때 가장 잘 따릅니다. 역할과 규칙은 합쳐서 2,500자 안쪽을 권합니다.

## 내 자료로 정확하게 답하게 하려면

작은 AI는 자료에 뜻이 적혀 있지 않은 낱말을 상식으로 채우는 경향이 있습니다. 예를 들어 "상점"을 칭찬 점수가 아닌 가게로 이해하고 답을 지어낼 수 있습니다. 자료를 만들 때 아래를 지키면 크게 좋아집니다.

- 맨 앞에 **한눈에 보기**를 두고, 헷갈릴 수 있는 낱말의 뜻을 적습니다. 예: "상점은 좋은 행동을 했을 때 받는 칭찬 점수입니다. 물건을 파는 가게가 아닙니다."
- **자주 묻는 질문과 답**을 끝에 적습니다. "상점이 뭐예요?"처럼 학생이 실제로 물을 문장 그대로 적습니다.
- "※ 이 자료는 가상입니다" 같은 **안내 문구는 자료 본문에 넣지 않습니다.** AI가 그 문구를 답에 옮깁니다.
- `## 제목`으로 주제를 나누고, 한 줄에 한 가지 사실을 적습니다.

## 챗봇 만들기 실습

- **챗봇 이름**을 정하면, 대화에서 AI 대신 그 이름으로 답합니다.
- **예시 역할** 버튼(친절한 도우미, 영어 선생님, 글 다듬기, 퀴즈 진행자, 고민 상담 친구)을 눌러 시작한 뒤 내 챗봇에 맞게 고칩니다.
- **내 챗봇 공유하기**를 누르면 링크가 복사됩니다. 다른 사람이 그 링크를 열면 같은 이름, 역할, 규칙의 챗봇이 열립니다. 넣은 자료(지식 파일)는 링크에 담기지 않습니다.
- 여러 명이 같이 써도 서로 느려지지 않습니다. 각자 자기 브라우저에서 AI가 돌아가기 때문입니다. 다만 처음 AI 파일(약 1GB)은 기기마다 받아야 하니, 수업 전에 **AI 준비하기**를 미리 눌러 두면 좋습니다.

## Ollama를 웹에서 쓰려면

인터넷 주소에서 내 PC의 Ollama를 부르려면 한 번 설정이 필요합니다.

- Windows: 명령 프롬프트에서 `setx OLLAMA_ORIGINS "*"` 실행
- macOS: 터미널에서 `launchctl setenv OLLAMA_ORIGINS "*"` 실행
- 그다음 Ollama를 완전히 종료했다가 다시 켭니다.

`"*"`는 모든 웹사이트를 허용합니다. 이 페이지 주소만 허용하려면 `"*"` 대신 그 주소를 넣으세요.

## 개인정보

- 대화 내용과 설정은 이 브라우저(localStorage)에만 저장됩니다.
- API 키는 이 브라우저에만 저장되고, 고른 AI 서비스로만 보내집니다. 공용 PC에서는 다 쓴 뒤 **지우기**를 눌러 주세요.
