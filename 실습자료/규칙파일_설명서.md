# 챗봇 만들기 실습 안내서

**오늘 만들 챗봇:** 새솔고 학생회 도우미
학생이 상점, 벌점, 학교 일정을 물어보면 자료를 찾아 답해 주는 챗봇입니다.

> 이 실습에 나오는 새솔고등학교, 규정, 일정은 모두 **실습을 위해 지어낸 가상의 내용**입니다.

---

## 준비물

실습 자료 3개를 내 컴퓨터에 받아 둡니다.

| 파일 | 넣는 곳 | 내용 |
|---|---|---|
| `규칙_학생회도우미.txt` | 3단계: 답변 규칙과 흐름 | 챗봇이 답할 때 지킬 규칙 5개 |
| `참고자료_상점벌점규정.txt` | 4단계: 참고 자료 | 상점과 벌점을 주는 경우, 누적 조치, 이의 신청 |
| `참고자료_주요일정.pdf` | 4단계: 참고 자료 | 2026학년도 시험, 행사, 방학 일정 |

받는 방법: GitHub의 `실습자료` 폴더에서 파일을 누르고, 오른쪽 위의 **다운로드(Download raw file)** 버튼을 누릅니다.

---

## 따라 하기

### 0단계: 사이트 열고 AI 준비하기

1. Chrome이나 Edge로 실습 사이트를 엽니다.
2. 대화 화면 가운데의 **AI 준비하기**를 누릅니다.
3. 처음 한 번은 몇 분 걸립니다. 기다리는 동안 1~4단계를 해도 됩니다.

### 1단계: 챗봇 이름

`새솔고 학생회 도우미`라고 적습니다.

### 2단계: 역할

역할 칸의 내용을 지우고, 아래 내용을 붙여 넣습니다.

```
당신은 새솔고등학교 학생회의 안내 도우미입니다. 학생들에게 상점, 벌점, 학교 일정을 친절하게 알려 줍니다. 한국어 존댓말로, 쉬운 말로 답하세요.
```

### 3단계: 답변 규칙과 흐름

1. **규칙 파일 불러오기**를 누르고 `규칙_학생회도우미.txt`를 고릅니다. 파일을 칸에 끌어다 놓아도 됩니다.
2. 칸에 규칙 5개가 채워졌는지 확인합니다.
3. **역할과 규칙 적용**을 누릅니다.

### 4단계: 참고 자료

1. **파일 고르기**를 누르고 `참고자료_상점벌점규정.txt`와 `참고자료_주요일정.pdf`를 함께 고릅니다.
2. 아래 목록에 두 파일이 보이면 끝입니다.

### 5단계: 시험해 보기

아래 [시험 질문](#시험-질문)을 하나씩 보내 봅니다.
답변 아래 **참고한 자료**를 누르면, AI가 어느 문장을 보고 답했는지 볼 수 있습니다.

### 6단계: 공유하기

**내 챗봇 공유하기**를 누르면 링크가 복사됩니다. 친구에게 보내면 같은 이름, 역할, 규칙의 챗봇이 열립니다.
참고 자료는 링크에 담기지 않으므로, 친구도 4단계를 해야 합니다.

## 역할, 규칙, 참고 자료는 무엇이 다른가요?

| | 역할 | 답변 규칙과 흐름 | 참고 자료 |
|---|---|---|---|
| 정하는 것 | 챗봇이 **누구인지** | 챗봇이 **어떻게 답할지** | 챗봇이 **무엇을 알고 있는지** |
| 예시 | 학생회 안내 도우미 | 세 문장 이내로 답하기 | 벌점 규정, 학교 일정 |
| 비유 | 직업 | 업무 수칙 | 업무 자료집 |

참고 자료는 질문할 때마다 **관련 있는 부분만** 찾아서 AI에게 보여 줍니다. 그래서 자료가 길어도 괜찮습니다.

## 예시 규칙 파일 한 줄씩 보기

| 규칙 | 이렇게 쓴 이유 |
|---|---|
| 1. 사용자가 인사만 하면 "안녕하세요! 새솔고 학생회 도우미입니다. 상점, 벌점, 학교 일정을 물어보세요."라고 답하세요. 질문에 답할 때는 인사하지 마세요. | **말할 문장을 따옴표로 정확히** 주면 AI가 그대로 따라 하기 쉽습니다. "질문에 답할 때는 인사하지 마세요"를 덧붙인 것은, 처음 버전에서 AI가 모든 답 앞에 인사를 붙였기 때문입니다. **언제 적용하는 규칙인지**를 분명히 적어야 합니다. |
| 2. 질문이 무엇을 묻는지 애매하면, 상점, 벌점, 일정 중 무엇이 궁금한지 먼저 물어보세요. | 대화의 **흐름**을 정하는 규칙입니다. 애매한 질문에 아무 답이나 하지 않게 합니다. |
| 3. 점수, 날짜, 시간, 장소는 참고 자료에 적힌 그대로 말하세요. | 틀리면 안 되는 정보를 **구체적으로 짚어** 줍니다. |
| 4. 참고 자료에 없는 질문에는 "그 내용은 자료에 없어요. 학생회실(본관 2층)에 물어보세요."라고만 답하세요. | AI가 **모르는 것을 지어내지 않게** 하는 규칙입니다. 대신 갈 곳을 알려 줍니다. |
| 5. 답은 세 문장 이내로 짧게 하세요. | 길이를 **숫자로** 정하면 잘 지킵니다. "짧게"보다 "세 문장 이내"가 낫습니다. |

---

## 좋은 규칙을 쓰는 6가지 방법

1. **번호를 붙여 한 줄에 하나씩** 씁니다.
2. **3~5개**가 가장 좋습니다. 규칙이 많으면 작은 AI는 뒤쪽 규칙을 잊어버립니다.
3. **"하지 마세요"보다 "하세요"**로 씁니다. "길게 쓰지 마세요"보다 "세 문장 이내로 하세요"가 잘 통합니다.
4. **꼭 말해야 하는 문장은 따옴표로** 정확히 적습니다.
5. **숫자로 정합니다.** "짧게"보다 "세 문장 이내", "몇 개"보다 "세 개"가 낫습니다.
6. **고치고 다시 시험합니다.** 규칙을 바꾸면 **역할과 규칙 적용**을 누른 뒤 같은 질문을 다시 보내 봅니다.

## 나만의 규칙 파일 만들기

메모장에 아래 틀을 붙여 넣고 `[ ]` 부분을 채운 뒤, `.txt`로 저장합니다.

```
1. 사용자가 인사만 하면 "[챗봇의 첫인사 문장]"이라고 답하세요. 질문에 답할 때는 인사하지 마세요.
2. [이런 질문]이 오면, 먼저 [이것]을 물어보세요.
3. [점수, 날짜, 가격 등 틀리면 안 되는 것]은 참고 자료에 적힌 그대로 말하세요.
4. 참고 자료에 없는 질문에는 "[모를 때 할 말]"이라고만 답하세요.
5. 답은 [몇] 문장 이내로 하세요.
```

저장할 때 인코딩을 **UTF-8**로 하면 한글이 깨지지 않습니다. Windows 메모장은 기본이 UTF-8입니다.

## 시험 질문

| 질문 | 기대하는 답 | 확인할 규칙 |
|---|---|---|
| 안녕하세요 | "안녕하세요! 새솔고 학생회 도우미입니다. 상점, 벌점, 학교 일정을 물어보세요." | 1 |
| 지각하면 벌점 몇 점이에요? | 지각 1회마다 벌점 1점 (오전 8시 20분 이후) | 3, 5 |
| 체육대회는 언제예요? | 5월 15일(금) 오전 9시, 운동장 (비 오면 5월 22일) | 3 |
| 욕설 벌점을 상점으로 지울 수 있나요? | 아니요. 욕설 벌점과 무단 결석 벌점은 지울 수 없음 | 3 |
| 벌점이 10점이 되면 어떻게 돼요? | 학생부 선생님과 상담하고 반성문을 씀 | 3 |
| 새솔제 공연은 몇 시에 해요? | 10월 16일(금) 오후 2시, 강당 | 3 |
| 오늘 급식 메뉴 알려 주세요 | "그 내용은 자료에 없어요. 학생회실(본관 2층)에 물어보세요." | 4 |
| 점수 알려 주세요 | 상점, 벌점, 일정 중 무엇이 궁금한지 되묻기 | 2 |

브라우저 안의 AI는 작은 AI라서 **모든 답이 기대대로 나오지는 않습니다.** 어떤 질문에서 규칙을 어기는지 찾고, 규칙을 고쳐 보는 것이 이 실습의 핵심입니다.

**미리 시험해 본 결과** (같은 계열의 작은 AI로 두 번씩 시험):
- 점수, 날짜, 시간, 장소를 묻는 질문 6개는 모두 자료대로 맞혔습니다.
- **"오늘 급식 메뉴 알려 주세요"**(규칙 4)와 **"점수 알려 주세요"**(규칙 2)는 자주 틀렸습니다. 급식 메뉴를 지어내거나, 되묻지 않고 인사만 했습니다.
- 이 두 질문으로 **규칙 고치기 연습**을 해 보세요. 예: 규칙 4를 1번으로 올리기, "급식"처럼 자료에 없는 주제를 규칙에 직접 적기.

## 잘 안 될 때

| 이런 일이 있으면 | 이렇게 해 보세요 |
|---|---|
| 규칙을 바꿨는데 그대로예요 | **역할과 규칙 적용**을 눌렀는지 확인합니다. |
| 자료에 있는 내용인데 엉뚱하게 답해요 | 답변 아래 **참고한 자료**를 열어 봅니다. 맞는 문장을 찾았는데 틀렸다면 AI의 실수이고, 못 찾았다면 질문에 자료 속 낱말(예: "체육대회")을 넣어 다시 물어봅니다. |
| 자료에 없는 걸 지어내요 | 작은 AI가 가장 어려워하는 부분입니다. 규칙 4를 맨 위(1번)로 옮겨 보거나, 대화할 AI를 **Qwen 2.5 3B**로 바꿔 봅니다. |
| 답이 너무 길어요 | 규칙의 문장 수를 줄입니다. 예: "두 문장 이내". |
| 한글이 깨져요 | 규칙 파일을 UTF-8로 다시 저장합니다. |
| PDF를 넣었는데 못 읽어요 | 스캔한 그림 PDF는 글자를 읽을 수 없습니다. 글자를 복사할 수 있는 PDF여야 합니다. |
| 대화가 길어지니 이상해져요 | **새 대화**를 누릅니다. 역할, 규칙, 자료는 그대로 남습니다. |

## 참고 자료를 직접 만들 때

- **`## 제목`으로 주제를 나눕니다.** 챗봇이 관련 부분을 더 잘 찾습니다.
- **한 줄에 한 가지 사실**을 씁니다. 예: "지각 1회마다 벌점 1점을 받습니다."
- **질문에 나올 낱말을 그대로** 씁니다. 학생이 "벌점"이라고 물을 것 같으면 자료에도 "벌점"이라고 씁니다.
- **자주 묻는 질문과 답**을 자료 끝에 적어 두면 정확도가 올라갑니다.

## 응용: 다른 챗봇 만들어 보기

같은 방법으로 주제만 바꾸면 다른 챗봇이 됩니다.

- **급식 안내 챗봇:** 참고 자료는 한 달 급식표, 규칙은 "알레르기 성분을 꼭 함께 알려 주세요".
- **동아리 소개 챗봇:** 참고 자료는 동아리 소개 글, 규칙은 "마지막에 가입 방법을 알려 주세요".
- **도서관 안내 챗봇:** 참고 자료는 이용 안내, 규칙은 "책 제목을 물으면 몇 층에 있는지 알려 주세요".
